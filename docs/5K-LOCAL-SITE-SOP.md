## Unit economics (fix this)

₹5,000 is **not** a software project. It is:

**AI-built brochure site + 1 year keep-it-online.**

| Item | Wrong (your 60–70%) | Right |
| --- | --- | --- |
| Domain `.com` / `.in` | bundled into expensive host | **₹500–1,200** (Buy with **client’s name + email** — Cloudflare / Namecheap / GoDaddy, no upsells) |
| Hosting | Hostinger/GoDaddy “business” ₹3–5k | **₹0–2,000**: Vercel / Netlify / Cloudflare Pages for static site. Hostinger **single** shared only if they insist on cPanel/WordPress |
| SSL | paid | **Free** |
| Email @domain | included | **Not included** at ₹5k (Zoho is extra) |
| Your time | 3 people × days | **1 person × 6–10 hours** using a template + AI |
| **COGS** | ₹3,000–3,500 | **₹800–2,500** |
| **Gross left** | ₹1,500–2,000 | **₹2,500–4,200** |

Three people splitting ₹2,000 is a loss. One person, one template, 1 day = acceptable **seed cash + review**.

**Do not spend 60–70% on hosting.** That is GoDaddy/Hostinger upsell. You keep the margin; infra stays cheap.

Year 2 is the real product: **renewal ₹3,000** (almost pure margin if hosting is free/cheap). Say it on day 1.
